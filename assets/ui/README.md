# Imagens do menu

`cover.png` e `umd.png` sao as duas fotografias fornecidas pelo usuario em 16/11/2026. Os arquivos foram preservados integralmente, sem geracao de imagem nem alteracao dos pixels.

O menu desenha cada fotografia mantendo sua proporcao. O UMD inclui sua carcaca plastica; nao recebe mascara circular nem furo artificial. A fotografia da capa identifica uma edicao japonesa de relancamento; ela nao e usada para determinar a compatibilidade da ISO.

A identidade e a versao dos arquivos de origem foram preservadas nos metadados NTFS. A interface le esses arquivos no primeiro F1 de cada sessao; para trocar uma imagem, reinicie o jogo apos substitui-la.
